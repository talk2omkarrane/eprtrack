RECOMMENDED COLUMNS

Name columns this way

Invoice No→ unique invoice / transaction reference
Product→ product or SKU name
Quantity→ sales / transaction quantity
Quantity Unit→ kg or tonnes
Invoice Date→ transaction date
Packaging Type→ rigid, film, pouch, etc.
Packaging Weight (kg)→ plastic packaging weight
EPR Category→ I, II, III or IV

If your file uses different names, EPRTrack tries to map common alternatives automatically. You can review the mapping before analysis.
